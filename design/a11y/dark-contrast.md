Generated by `/workspace/omcp-v0118/contrast.py` (copy: `a11y/dark-contrast.py`, works for both themes: `contrast.py MOCKUPS OUT.json light|dark`) + `table18.py`. Every visible element in all **81 `.phone.dark` frames** (incl. the new Hebrew frames) was rendered in Chrome (Playwright, `/usr/bin/google-chrome`) and measured: text, icons (first painted stroke/fill of each SVG ≥ 8 px), control boundaries (toggle track + thumb, checkboxes, radios, inputs, outlined/secondary buttons, tags, segmented controls, round action buttons, dashed/hatched placeholder tiles) and focus rings. Backgrounds are composited through every ancestor (alpha + opacity); gradients and hatches use the **worst stripe**.

## Other fixes (both themes)

- `nearby-skeleton`: the loading action row used `opacity:.4` (1.1–2.5:1). Now `.is-loading` + `aria-disabled="true"`: `--surface-2` fill, `--line-strong` ring, `--ink-3` glyph — ≥ 3:1 in both themes.
- `restore-password` (lockout) and `settings-storage` (edit-off): opacity-dimmed controls replaced with the same semantic disabled treatment (`.btn.disabled`, `.is-disabled`).
- Inverse toasts (`background:var(--ink)`): accent uses the other theme’s teal (`#3dbdb6` on the light theme’s near-black toast, `#0b6e6a` on the dark theme’s near-white toast). Was 2.84:1.
- `mod-stream` host line: `opacity:.75` (also faded the reputation chip to 2.2:1) → `color:rgba(255,255,255,.88)`.
- “Ask to resend” pills: 35 % brand border (1.7:1) → full `--brand`.
- Photo scrims: `media-missing` “Restored” pill .55 → .72, `nearby-area` report button .45 → .62, so white stays ≥ 4.5:1 / 3:1 even over a white photo region.
